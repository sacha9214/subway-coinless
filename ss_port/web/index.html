How it plays

Nothing here is learned and nothing looks at the screen. The game on this page is a Rust port of the web version whose simulation is deterministic: the same seed and the same key presses always give the same run.

So the planner searches the game itself. Every 4 frames it takes every position the run could be in and tries each key: nothing, left, right, jump, roll. Anything that crashes or touches a coin is thrown away. What survives ten minutes is a list of key presses, and this page replays that list.

After the ten minutes the keys stop, so the run ends in a crash a moment later.

Code and details: github.com/sacha9214/subway-nocoin.
